🚗 RideX - Full Stack Ride Booking System

🔥 Features
- Book Ride (React UI)
- Payment Simulation (GPay, PhonePe, Card)
- Auto Driver Assignment (Spring Boot)
- MySQL Database Integration
- Ride Tracking UI
- Driver Flow Simulation

🛠 Tech Stack
Frontend: React, CSS  
Backend: Spring Boot, Java  
Database: MySQL  

🚀 How to Run
## Backend
cd backend
mvn spring-boot:run

### Frontend
cd frontend
npm install
npm start
